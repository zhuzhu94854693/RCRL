As shown in Figure 1, The RCRL framework constructs reliable change evidence from heterogeneous image pairs through two complementary processes: multi-scale structural evidence construction and residual-anchored difference refinement. Given two heterogeneous images, a shared feature extractor first establishes a common representation. Multi-scale patch spatial self-similarity then captures complementary local structural relationships, while a handcrafted multi-cue difference provides an explicit anchor for a residual branch that learns complementary corrections from cross-temporal features, patch correspondence, and structural information. Pseudo-label supervision and consistency constraints provide additional training guidance, with reliable predictions incorporated to update the supervisory signal during optimization. The refined primary difference probability is used to generate the final change map.
